FuturLab Privacy Policy

FuturLab processes only the information needed to provide authorized content management and publishing workflows.

Authentication and authorization data received from connected platforms is used only to provide the functionality explicitly authorized by the account owner.

FuturLab does not sell personal data to advertisers. Access credentials, tokens and platform authorization data are not intentionally exposed publicly.

YouTube API Services

FuturLab uses YouTube API Services when a user connects a YouTube account. Depending on the features the user authorizes, FuturLab may use the YouTube Data API to upload videos to the user's YouTube channel and to retrieve limited information about those uploads, such as the YouTube video identifier, visibility/status and basic performance statistics.

FuturLab does not request or store a user's YouTube or Google password. OAuth authorization tokens needed to maintain the authorized connection may be stored securely for the publishing workflow. YouTube API Data is used only to provide the user-requested publishing, status and analytics functions and is not sold to advertisers.

Use of YouTube API Services is also subject to Google's Privacy Policy.

A user can revoke FuturLab's access to their Google/YouTube account from Google Security permissions. A user may also contact FuturLab at the address below to request deletion of stored authorization data and YouTube API Data. Following a valid revocation or deletion request, FuturLab will delete the applicable stored Authorized Data as soon as reasonably possible and within the period required by the YouTube API Services policies.

Data requests and deletion

Users may request information about their stored data or request deletion by contacting FuturLab. Where an authorization can no longer be validated, FuturLab may also remove the related stored API authorization data.
